# QA register

One row per gate evaluation worth recording (a `make check` run that changed what is known).
Result: `PASS · FAIL · WAIVED (AUTHOR, YYYY-MM-DD)`. A PASS or FAIL names the date, the commit
evaluated and the evidence. Kept by the project-manager agent, who records and performs none.
