# Source library

PDF/DJVU of papers and books backing the cocycle-structure work. **Binaries are git-ignored**
(see [`.gitignore`](.gitignore)) — they live here locally but are not committed (size + copyright).
This catalogue *is* tracked, so the bibliography survives even though the files don't.

## Conventions

- **Filename:** `<lastname><year>-<slug>.pdf` (or `.djvu`), lowercase, e.g. `steiner1977-cycles.pdf`.
- Every file added here gets **(a)** a catalogue row below and **(b)** a reading note in
  [`../notes/`](../notes/) once read (template: [`../notes/_TEMPLATE.md`](../notes/_TEMPLATE.md)).
- Drop the file in, then update both this table and [`../KNOWLEDGE_MAP.md`](../KNOWLEDGE_MAP.md).
