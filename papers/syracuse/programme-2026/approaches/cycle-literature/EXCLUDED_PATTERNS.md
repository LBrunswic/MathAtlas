# Excluded / characterized cycle patterns — 3x+1 (Collatz / Syracuse) and relatives

Exhaustive backing for [`SURVEY.md`](SURVEY.md) §2. Every paper that **proves a specific cycle
shape/pattern impossible** for the 3x+1 / 3x+d / qx+r maps, or that **characterizes** the cycle
pattern space. Maintained by the [`excluded-patterns`](../../.claude/skills/excluded-patterns/SKILL.md)
skill. Honest labelling: a pattern is `verified` only if confirmed from the paper, its abstract,
or a reliable secondary source (Lagarias's annotated bibliographies are treated as reliable
secondary). A literal `?` means the precise pattern could not yet be read.

**Notation.** $m$ = number of local minima = number of maximal odd-step runs = number of
"circuits"/descents in the cycle's parity word. A **1-circuit** is one run of odd steps followed
by one run of halvings ($m=1$). $(k,l)$ = (odd steps, even/halving steps); $K=o$ odd steps,
$K+L=E$ total halvings in [`SURVEY.md`] notation. $d,q,r$ index the generalized $3x+d$ / $qx+r$
maps. Most bounds are **conditional** on the numerically verified range $N_0$.

## Notes / caveats

- **Atkin 1966** rules out a period-41 cycle of Klamkin's *original Collatz permutation*, **not**
  the 3x+1 map — kept for completeness but flagged.
- **Garner 1981/1985** are about coefficient stopping time and heights, **not** cycle-shape
  exclusion; kept with an explicit "not a cycle exclusion" tag.
- **Halbeisen–Hungerbühler, Eliahou, Crandall, Sinisalo** bound cycle *length* (number of steps),
  which excludes every short pattern; they are length-based, not $m$-based, exclusions.
- The headline $m$-record is **Hercher 2023 ($m\le91$)**, now listed in the *Recent literature
  (2015–2026)* section. No paper rules out $m\ge92$; that gap is the cycle part of Collatz.
- **Barina (2021, 2025)** verification papers fix the smallest-cycle-element floor $N_0$
  ($1.5\cdot2^{70}$ then $2^{71}\approx2.36\times10^{21}$). They imply "no cycle with any element
  $\le N_0$" but exclude **no parity-word shape** — they are the $N_0$ input the $m$-bounds
  consume. Catalogued in [`SURVEY.md`] §4, not as a shape-exclusion row.
- **Tao 2019** (a.e. density) and the LLM-assisted **Chang 2026** survey are included only with
  explicit caveats so the table stays honest.
- Still to mine on a future run: Rozier's "Lower Bound Hypothesis" (ipgp.fr LBHv4.pdf) and
  arXiv:2502.00948 (paradoxical behavior) / 2306.15284 (Collatz–abc); the older arXiv cycle
  notes 1208.2556 (Bork 2012) and 1010.6206 (two remarks, 2010), 0907.3086 (R. Ghosh 2009).
