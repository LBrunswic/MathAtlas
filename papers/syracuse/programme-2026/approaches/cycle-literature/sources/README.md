# sources/ — downloaded papers for the excluded-patterns table

PDF/DjVu copies of papers backing
[`EXCLUDED_PATTERNS.md`](../EXCLUDED_PATTERNS.md). Binaries are **git-ignored** (see
`.gitignore`); this README is the tracked catalogue. When you drop a file here, the
[`excluded-patterns`](../../../.claude/skills/excluded-patterns/SKILL.md) skill (`--ingest`)
reads it, transcribes the exact cycle pattern into the table, and adds a line below.

Filename convention: `<firstauthor><year>.pdf` (e.g. `steiner1977.pdf`, `simonsdeweger2005.pdf`).
