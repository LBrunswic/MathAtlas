Notation conventions

Canonical, project-wide (fixed in diophantine):

  • Accelerated (odd-to-odd / Syracuse) map. \(a_0\) is an odd start; \(a_1, a_2, \dots\) are the successive odd terms produced by \(a_{k+1} = (3a_k+1)/2^{\,e_{k+1}-e_k}\) (apply \(3x+1\) once, divide out all factors of \(2\)).
  • \(e_k\) = number of even steps before the \(k\)-th odd term, \(e_0 = 0\). Equivalently \(e_{k+1}-e_k = \nu_2(3a_k+1) \ge 1\); \((e_k)\) strictly increasing.
  • \(o\) = index of the final odd term under consideration.
  • Equivalence: parity-manipulation’s \((b_k, x_k, n)\) are the same objects as \((e_k, a_k, o)\) — same accelerated map, identical identity. The \(b/x/n\) vs \(e/a/o\) choice is purely notational.

Core identity

Diophantine closed form. For an odd start \(a_0\) and any \(o \ge 1\), \[2^{e_o}\,a_o \;-\; 3^{o}\,a_0 \;=\; \sum_{k=0}^{o-1} 2^{e_k}\,3^{\,o-1-k}.\] The identity is algebraic: it needs only the recurrence \(2^{e_{k+1}-e_k}a_{k+1}=3a_k+1\), not oddness or positivity — so it holds over \(\mathbb{Z}\), \(\mathbb{Q}\), and \(\mathbb{Z}_2\). Oddness (\(e_{k+1}-e_k=\nu_2(3a_k+1)\)) is only needed to identify the sequence as a genuine Syracuse orbit. — diophantine · proof status: STATUS (skeleton verified, formal write-up pending)

2-adic reconstruction. For a strictly increasing \((b_k)_{k\ge0}\) with \(b_0=0\), there is a unique trajectory in \(\mathbb{Z}_2\) with that parity behavior, with start \[x_0 = -\sum_{k=0}^{\infty}\frac{2^{b_k}}{3^{k+1}} \in \mathbb{Z}_2.\] The map (strictly increasing \((b_k)\)) \(\leftrightarrow\) (\(x_0 \in \mathbb{Z}_2\)) is a bijection. — parity-manipulation

Partial results

parity-manipulation

General single-block shift. For \(b'_k = b_k + a\,\mathbf{1}_{k>q}\) (\(a\in\mathbb{Z}\), \(a > -c_{q+1}\)): \[x_0 - x'_0 = -(2^a-1)\,2^{b_{q+1}}\,x_{q+1}/3^{q+1}.\] — STATUS

Integrality theorem. For integer trajectories, \(x_0 - x'_0 \in \mathbb{Z} \iff 2\cdot 3^q \mid a\). Minimal admissible shift \(a = 2\cdot 3^q\). Positive \(a\) → predecessor moves; negative \(a\) (with \(|a|\le c_{q+1}-1\)) → successor moves. — STATUS

3-adic / LTE lemma. \(\nu_3(2^a-1) = 0\) if \(a\) odd, \(=1+\nu_3(a)\) if \(a\) even; equivalently \(\operatorname{ord}_{3^{q+1}}(2) = 2\cdot 3^q\). — STATUS

Finite-support no-go. If \(b'_k - b_k = 0\) for all \(k \ge N\), then \(x'_k = x_k\) for all \(k \ge N\): any finite-support perturbation only re-routes the past of a fixed downstream node — it stays inside the inverse Collatz tree. New content requires infinite-support perturbations. — STATUS
