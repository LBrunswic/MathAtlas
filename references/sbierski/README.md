# Jan Sbierski's work and topological causality: a literature knowledge base

Built 2026-11-20 with the lit-review skill (two rounds, 29 papers read, 279 verified quotes).
Start with `SYNTHESIS.md`; `INDEX.md` lists every source with its trust tier; `notes/<key>.md` holds
one note per paper with verbatim quotes checked against `text/<key>.txt`; `rounds/` holds the
plans, summaries and the reader brief. `INDEX.md` and `refs.bib` are generated (`kb.py render`).
PDFs are not committed (see `.gitignore`).
