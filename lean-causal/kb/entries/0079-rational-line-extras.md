An irrational point of `Causal.rationalLine` is ≤-related to itself only
(`rationalLine_eq_of_le_irrational`), so no diamond has interior (`rationalLine_openDiamond`: not
tarentin), and J_M(p, q) = ℚ ∩ [p, q] for rationals p, q is not closed (`rationalLine_diamond_top`:
not causally compact). ≪ is empty: not plain, no chronal neighbours. The identity is a time function
and open intervals are causally convex (open strong causality). It is absolutely minimal on every open
set for every cover (`rationalLine_absolutelyMinimalOn`), so `Causal.rationalLine_separates`
(`Causal.RationalLineExtras`) witnesses X ⇏ locally_causally_open(_future) in either reading of
`defi:causalite` (OQ-18) (T-abs-rational-line-extras).
