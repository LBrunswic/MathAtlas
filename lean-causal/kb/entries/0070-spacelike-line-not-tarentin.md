kind: pattern
created: 2026-11-21

`Causal.spacelikeLine` (≤ the diagonal) has empty open diamonds (`interior_singleton`), so it is not
tarentin, while globally hyperbolic, strongly causal (both forms), causally open, absolutely minimal,
push-up, with a time function — the first model proved GH and not tarentin
(`spacelikeLine_separates_tarentin(_full)`, `Causal.NestedTransfer`). A transfer along a nesting that
reads only ≤ (causally convex sets, diamonds, a time function) needs ≤ nested at M only: state the
`_of_le_top` form and derive `LeNested.*` from it; tarentin, which reads interiors of diamonds, passes
to the WIDER causality instead (`LeNested.tarentin_wider`) (T-abs-nested-transfer).
