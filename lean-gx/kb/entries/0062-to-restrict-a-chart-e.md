Found by T-bbs-photon-circles. To restrict a chart e : M → X to subsets C ⊆ M and T ⊆ X that it matches on its source (x ∈ C ↔ e x ∈ T), use GX.restrictMatch, an OpenPartialHomeomorph C T. Apply restrOpen first to handle a C that is only relatively open (GX.photonChartOf).
