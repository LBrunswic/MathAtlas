Rigidity of a normalised linear action on S(V): GX.eq_smul_of_eventually_eigen says that if the eigenvectors fill a neighbourhood of some v0 != 0, the map is a scalar (compare v0 + s w with v0 + 2 s w). Feed it GX.eventually_eigen_of_eqOn. If a preserved form takes a nonzero value, the scalar is 1. Without such a form, GL(V) is not faithful (GX.lem_analytique_counterexample).
